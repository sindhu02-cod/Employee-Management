# Employee Management System

A full-stack Employee Management System developed as part of a Full Stack Web Development internship project.

The application allows users to add, view, update, delete, search, and filter employee details through a simple and responsive web interface.

## 🚀 Features

- Add new employees
- View all employees
- Update employee details
- Delete employees
- Search employees by:
  - Name
  - Email
  - Department
- Filter employees by department
- Display total number of employees
- Responsive user interface
- REST API integration
- MongoDB database integration

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose
